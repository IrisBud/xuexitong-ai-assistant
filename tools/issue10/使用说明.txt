学习通 Issue #10 题目结构采集包
适用：Windows + Chrome / Edge + Tampermonkey（油猴）

先做最少的准备
1. 回到原来报错的具体小节，保留“多选题 + 判断题”的答题页。
2. 在原学习助手里点“停止”，关闭答案预览；采集期间不要点开始自动、暂时保存、提交或重做。
3. 如果页面发灰，顶部显示“已在调试程序中暂停”，在开发者工具里按 F8 继续，然后关闭 F12。
   如果立刻又暂停，不用反复尝试，把这个情况告诉作者。

推荐方法：临时采集器
1. 解压本压缩包。里面的“学习通Issue10只读采集.user.js”是临时采集工具，不是修复版学习脚本。
2. 点击油猴图标 → 管理面板 → 实用工具 → 找“从文件导入 / Import from file”。
   选择这个 .user.js 文件，按页面提示安装。不要选择原来的正式学习脚本。
   如果看不到文件导入：右键 .user.js → 打开方式 → 记事本 → Ctrl+A、Ctrl+C；
   再到油猴管理面板点“+”新建脚本，Ctrl+A、Ctrl+V 替换默认内容，Ctrl+S 保存。
3. 回到刚才出问题的小节，刷新整页；不必重新开始自动运行。
4. 页面左下角会出现蓝色按钮“Issue 10：导出题目结构”。点它。
   预览会写明采到几个题目块。检查预览文字后，点“下载 JSON 文件”。
   浏览器应下载“学习通-Issue10-题目结构.json”，到下载列表确认即可。
5. 检查文件没有个人信息后，直接把 JSON 文件发给作者即可。
   若反馈平台不能附 JSON，可用记事本打开，另存为 .txt 后发送；不要只把文件截图。
6. 采完在油猴管理面板删除“学习通 Issue 10 只读结构采集器（临时）”。原学习脚本保留。

正常情况下，发回这一个 JSON 文件就够了，原 Issue 里两张截图已保留，不需要重截。
如果页面后来换了题或报错文字变了，再补一张“对应题目 + 完整报错”的截图。
如果“读取成绩”只发生在另一张页面，不必重新点开始去复现；下次自然出现时，停止后在那一页另采一次。
两个文件分别改名为“题型报错.json”和“读取成绩.json”，并写明分别在哪个界面。
不需要故意让电脑再休眠，也不用重测 AI 接口或消耗模型额度。

点击后显示“没有找到题目” / 一直只有 0 个
• 题目可能在独立子页面里。如果题目区域左下角也有同名按钮，点题目附近的那个按钮。
• 外层页采不到跨域子页是浏览器限制，不代表你操作错了。
• 如果没有内部按钮、按钮被挡住、点了没有下载、或者一直0个，改用下面的备用方法。
• 若你看到3题但文件只采到2题，告诉作者缺的是哪一题；不需要反复重试。

备用方法（仅推荐方法失败时用，不需要两套都做）
1. 停止原脚本，保持出问题的答题页；按 F12 → 选择“元素 / Elements”。
2. 按 Ctrl+Shift+C，点击第一题的题干文字。
3. 开发者工具会选中一行 HTML。逐层选它的上一级节点：
   鼠标悬停该节点时，页面高亮区域需要覆盖“第一题题型 + 题干 + A/B/C/D所有选项”。
   不要选整个网页，也不要选右边学习助手面板；不必懂标签名字。
4. 打开本包“备用-控制台采集.txt”，复制全部内容；切到F12的“控制台 / Console”，粘贴后回车。
   命令只读取刚选中的题目结构，不点击选项、不答题、不保存或提交。
   如果提示禁止粘贴，先阅读代码和浏览器提示；不愿继续或不能粘贴，停在这里把情况告诉作者即可。
   如果又出现“已在调试程序中暂停”，先按F8继续；反复暂停就不要继续折腾。
5. 显示“结构已复制”后，打开记事本，Ctrl+V，保存为“多选题结构.txt”。
   控制台返回 undefined 不代表失败，以粘贴到记事本后的内容为准。
6. 如果方便，对第二题判断题重复一次，保存为“判断题结构.txt”。
   优先发第一题即可；第二题用于对照，不要求把所有题逐一复制。

隐私与采集范围
• 工具只在你点采集按钮后读取当前题目；延迟出现的题目子页可能短暂轮询是否出现题目，以便显示按钮。
• 导出题型标记、HTML层级、输入控件类型、部分结构属性和点击函数名；不保留函数实参。
• 题干/选项正文、输入框内容、页面地址、图片/子页地址会隐藏；长数字/长ID会替换。
  会保留A/B/C/D、对/错、题型名称等短标签，及少量明确命名的短题型代码。
• 不读取Cookie、登录存储或API Key，不请求模型、不上传、不下载题图，不改变作答内容或平台完成标记。
• 自动处理无法保证清除所有特殊页面中的个人信息，发送前仍请简单检查。
• 不需要提供账号密码、Cookie、API Key、浏览器完整网页、HAR、Copy as cURL或油猴存储备份。

如果暂时不方便安装或使用F12，直接告知作者；不需要重复录像或尝试提交来证明问题。
