常见问题与故障排查

先看卡在哪一步，再收集必要信息。别用反复刷新、重复提交来碰运气。

按正式版 1.8.9 整理5 分钟阅读

没有学习助手面板

  1. 确认进的是具体小节正文，或已打开的独立作业，不是课程首页和目录。
  2. 在油猴里确认脚本已启用，浏览器允许用户脚本。
  3. 只保留一份控制这门课的脚本，然后刷新当前页面。
  4. 核对已安装版本。仅在电脑里下载了文件，还不算安装到油猴。

完整入口步骤见进入一条具体小节。课程使用学校自有域名时，再检查学校域名设置。

不切下一节

先保持课程标签在前台，查看当前视频是否有弹题、是否还显示“继续学习”，以及本节是否还有文档、测验等任务。视频结束和当前任务点变绿，不一定代表本节全部内容都处理完。

面板明确提示“平台未切换到下一节，请手动导航”时，先点停止，核对页面原生“下一节”和目录是否可用。自己打开下一条小节后，再点开始。不要把这种导航失败直接解释成 API 断连。

本课切节不需要多课程队列。队列显示为空、过期或账号不符时，按课程与队列区分处理。正式 1.7.7 的部分页面兼容问题仍需对应真实结构确认。

提示题型不支持

先记录题目显示的题型和完整提示，点停止。选项是方框或圆圈，只能帮助判断外观，不能单独证明脚本为什么识别失败。

可提供第一道失败题的脱敏截图或维护者指定的只读结构采集结果。题干、选项、编辑区、保存按钮和子页面关系，可能需要一起确认；不要只截错误提示。

不需要为了复现而重新提交、重做、休眠或切换到陌生题目。已经填过或提交过的内容先保留。

只读结构采集

如果脱敏截图无法说明题型问题，可按仓库的采集器使用说明补充必要结构。采集器独立于主助手，需先停用主助手的自动操作、关闭预览，再手动临时启用。

采集只用于识别控件和页面结构。导出前检查脱敏预览，反馈只附必要内容。结束后停用或移除采集器。

一直显示读取成绩

先看平台是否正在判题、待批阅，或者当前仍停留在原答题页。脚本状态文字不是成绩本身。

不要连续点提交或重做。结果不明时先停止，保留页面和已填写内容。反馈时说明平台有没有成功提示、成绩是否可见、是否曾手动刷新，以及脚本停在哪一句。

如果开发者工具显示 Paused in debugger，浏览器脚本可能被调试暂停。把这个状态单独说明，不要把它当成已经确认的题型或成绩读取根因。

出现验证码或人工验证

学习通出现滑块、图片验证码或已识别的人脸验证时，面板会变成琥珀色并提示手动处理，折叠时也能看到提醒。脚本会暂停播放、导航、预览和模型请求。请在学习通原有窗口手动完成验证。

验证消失或刷新页面后，仍可能保持人工暂停。先确认验证完成，再手动点击开始；不要为了恢复运行反复触发验证码。

正式考试、监考和平台禁止继续的情况，交回平台原有流程处理。

反馈时给这些信息

  1. 脚本版本、浏览器、油猴或其他脚本管理器版本。
  2. 预期做什么、实际停在哪一步；例如播放、读题、填写、保存、提交、等结果或切章。
  3. 面板完整提示，以及对应位置的一张脱敏截图。已有截图够用时，不必再重截。
  4. 涉及 AI 时给服务商、模型名和错误码；涉及页面结构时，再按维护者提供的只读采集方法补材料。

可以从“记录”区手动导出脱敏诊断，再自行决定是否上传。它不包含题目原文，也不会自动发给维护者。

GitHub Issue 是公开的。发送前遮掉姓名、学号、Cookie、Key、本地连接码和带私人参数的完整课程地址。不要导出整份油猴存储给别人。
