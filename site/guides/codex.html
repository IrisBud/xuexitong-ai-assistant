Codex 本地连接

先启动电脑上的连接服务，再把 18763 地址和连接码填进面板。使用期间保留服务窗口。

按候选版 1.8.1 整理6 分钟阅读

这篇讲什么
先确认命令行版可用解压完整源码，进对文件夹启动并选模型填入面板并测试下次启动和常见报错

先确认命令行版可用

需要 Node.js 20.11 或更高版本，以及已经登录的 Codex CLI。只装好或登录桌面版 Codex，不代表命令行版已可用。

node --version
npm --version
codex --version
codex login status

前三条应显示版本，最后一条应显示登录状态。缺少环境时，先按Node.js 官方下载和Codex CLI 官方说明完成安装登录。

解压完整源码，进对文件夹

  1. 下载并解压最新正式版源码 ZIP。
  2. 打开解压后的项目文件夹，能看见 package.json。
  3. Windows 文件管理器地址栏输入 powershell 并回车，在这个文件夹打开终端。
Test-Path .package.json

看到 True 再继续。显示 False 或报 ENOENT，说明终端位置不对；回到已解压、含该文件的文件夹重开。不要直接在 ZIP 内运行。

启动并选模型

npm run start:codex

依次用方向键和回车选择模型、推理强度。首次需要读取本机 CLI 模型目录，稍等即可；不确定时选择模型默认强度。

正常启动后，会看到本地地址 http://127.0.0.1:18763 和连接码文件位置。窗口停在这里等待浏览器连接是正常的，保持打开，不用继续输入命令。这个服务按教程启动不需要先执行 npm install。

模型列表可见不等于账号权限已验证。模型和强度以服务启动菜单为准，浏览器里其他 API 的模型下拉框、桌面聊天窗口的选项不会直接替本服务切换。

填入面板并测试

  1. 打开 src/local/bridge-token.txt，复制完整连接码。
  2. 学习助手“接口 → 添加 / 编辑接口”，选择本地 Codex。
  3. 地址填写 http://127.0.0.1:18763，Key 填连接码，先分配文字用途并保存。
  4. 点“测试 AI”。要处理图片，再分配图片用途并测试。

只启动服务不等于模型验证成功。正式 1.7.7 的测试会实际检查文字答案及已选图片用途，可能消耗模型用量；图片失败不推翻已经通过的文字结果。

连接码只用于这份本地服务，不要填写平台登录密码，也不要发给别人。

下次启动和常见报错

在原来含 package.json 的文件夹重新运行 npm run start:codex，确认菜单即可。地址和连接码没变时，面板保存的配置可以继续用。

现象处理
连接不上本机先看服务窗口是否还开着，再核对端口。服务窗口可以最小化，课程浏览器仍需前台。
401 / 连接码无效从当前服务文件夹的 bridge-token.txt 重新复制完整连接码。
npm.ps1 被系统策略阻止用 npm.cmd run start:codex，不需要为此修改系统执行策略。
想换模型服务窗口 Ctrl+C 停止，再运行启动命令，在菜单里重选。

关闭服务窗口或按 Ctrl+C 会停止服务。停止浏览器里的任务，只会取消本次等待，不等于撤销已发生的模型用量。

需要查原始说明或当前适配范围：

INSTALL.mdsrc/theme.jssrc/ai.jspackage.json
