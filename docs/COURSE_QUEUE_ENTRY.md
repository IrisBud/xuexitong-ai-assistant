# 课程列表与章节接续

只连续学习本课：打开具体小节，在学习助手点“开始自动”。不需要先创建多门课程队列。

连续学习多门课：打开个人空间或它的原生课程列表，在“学习助手 · 课程队列”浮窗里勾选、排序，然后显式开始。平台原生课程卡片不是脚本勾选框。空列表中的“打开课程列表”使用本页已有原生入口。

没有创建队列、读取不到账号、账号不一致、记录过期、记录损坏和入口改变会分别提示。继续队列先等存储确认；期间停止后不会自行启动。

本课原生“下一节”缺失或没有生效时，重读同课目录，至多点击一次唯一相邻且可用的小节标题。锁定、歧义或没有可靠入口时交回人工处理。仍需当前任务按规则处理；不改平台完成标记。

停止、答案预览、夜间休息、人工验证与账号隔离保护保留。模拟课程接续不等于真实课程完成或成绩。
