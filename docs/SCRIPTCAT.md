# 脚本猫与分发说明

当前默认安装和教程面向 Tampermonkey。现有脚本属于依赖课程网页的普通用户脚本；提交到脚本猫脚本站，不等于已经完成脚本猫扩展适配。

目前没有脚本猫上的实际安装和完整功能验收。不宣称标签页静音、跨页课程队列及全部功能在脚本猫中已经通过。专题阅读仍要求页面在前台并有焦点；更换管理器不提供稳定后台运行保证。不加入 @background 或可见性伪装。

- [脚本猫开发说明](https://docs.scriptcat.org/docs/dev/)
- [后台脚本说明](https://docs.scriptcat.org/docs/dev/background/)
- [接口说明](https://docs.scriptcat.org/docs/dev/api/)

## 可复制的脚本站介绍

本脚本支持学习通视频与音频播放、文档阅读、章节测验、讨论及作业辅助，并提供课程队列、章节搜索、多模型接入和主题切换等功能。

📖 详细功能介绍、安装教程、使用方法、版本更新及下载入口，请查看 [GitHub 项目](https://github.com/IrisBud/xuexitong-ai-assistant)。
